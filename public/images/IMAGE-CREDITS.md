# FORMA image provenance

All project imagery in `public/images/projects/` was made specifically for FORMA, a standalone fictional architecture-studio website intended to be shown later as a web-development portfolio project. The original image series was generated with built-in OpenAI ImageGen on 26 September 2026; the six comparison sketches were added on 16 October 2026. These images depict **concept architecture**, not photographed built projects. No third-party stock photo was bundled for the project galleries. There is no photographer to credit and no external photo license to carry forward; use of the generated output is subject to the applicable OpenAI terms. Keep this disclosure with the project if these images are republished.

The active site uses the `-v2.webp` series below. Each project has an exterior/establishing image, a detail and an interior that share the same building language and setting. These images were generated with built-in OpenAI ImageGen and encoded as WebP; hero/interior images are 1536 × 1024 pixels, while details are 960 × 1200 or 1024 × 1536 pixels. The older project files remain in the repository as an unused visual archive. They are documented in the table further below.

Keep the house and landscape recognizable, architectural, elegant and legible, with darker graphite along the important roof and window edges and quieter landscape lines. A full-bleed single drawing, 1536x1024 landscape, no paper border, no extra page margin, no tilt, no new objects, no crop, no sepia, no watercolor color, no labels, no handwriting, no measurements, no signature, no logo, no UI or comparison divider.
