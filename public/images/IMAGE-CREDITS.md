# FORMA image provenance

All project imagery in `public/images/projects/` was made specifically for FORMA, a standalone fictional architecture-studio website intended to be shown later as a web-development portfolio project. The images were generated with built-in OpenAI ImageGen on 26 September 2026 and depict **concept architecture**, not photographed built projects. No third-party stock photo was bundled for the project galleries. There is no photographer to credit and no external photo license to carry forward; use of the generated output is subject to the applicable OpenAI terms. Keep this disclosure with the project if these images are republished.

The active site uses the `-v2.webp` series below. Each project has an exterior/establishing image, a detail and an interior that share the same building language and setting. These images were generated with built-in OpenAI ImageGen and encoded as WebP; hero/interior images are 1536 × 1024 pixels, while details are 960 × 1200 or 1024 × 1536 pixels. The older project files remain in the repository as an unused visual archive. They are documented in the table further below.
