# Portfolio media provenance

Created 2026-09-28 using built-in OpenAI ImageGen (not the CLI). Higgsfield was evaluated: the connected workspace had 0 credits; Recraft preflight returned 1.25 credits per image. No Higgsfield generation was submitted.

These images depict fictional spaces and food for explicitly labeled concepts; they are not evidence of real clients, buildings, a licensed clinic or restaurant. Both 1600 px and 800 px WebP versions are committed under `media/`. No video was added. Original PNGs remain in the generation output, while portable optimized images live in this repository.
